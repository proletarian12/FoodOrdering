# 点餐小程序

基于 **uni-app（Vue 3）+ 微信云开发** 的堂食 / 外卖点餐小程序。包含用户端（点餐、支付）和**对普通用户完全隐藏的商家管理端**（菜品、订单、桌台、营业设置、统计）。

详细设计见 [设计文档.md](./设计文档.md)。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | uni-app（Vue 3），编译到微信小程序 |
| 后端 | 微信云开发：云函数 + 云数据库 + 云存储 |
| 登录 | 微信 openid（云函数自动获取） |
| 支付 | 微信支付（云开发 CloudPay） |
| 桌台码 | 微信小程序码（`wxacode.getUnlimited`） |

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置小程序 AppID

编辑 `src/manifest.json`，在 `mp-weixin.appid` 填入你的小程序 AppID（微信公众平台 → 开发 → 开发管理 → 开发设置）。

> 若暂时没有 AppID，可先用测试号开发，但**云开发和微信支付需要正式 AppID**。

### 3. 编译

```bash
npm run dev:mp-weixin
```

编译产物在 `dist/dev/mp-weixin/`。

### 4. 微信开发者工具导入

1. 打开微信开发者工具，选择「导入项目」。
2. 目录选择**本项目根目录** `AIFoodOrdering`（已配置 `project.config.json`，会自动识别 `miniprogramRoot` 和 `cloudfunctionRoot`）。
3. AppID 填你的小程序 AppID。

### 5. 开通云开发

1. 在微信开发者工具点击工具栏「云开发」，开通并创建一个环境（如 `cloud1-xxxxxx`）。
2. 将环境 ID 填入 `src/App.vue` 的 `wx.cloud.init({ env: '' })` 中（仅一个环境时可留空）。
3. 重新编译。

### 6. 部署云函数

在微信开发者工具中，对 `cloudfunctions/` 下的每个云函数（`user`、`dish`、`order`、`payCallback`、`merchant`、`init`）右键 → 「上传并部署：云端安装依赖」。

### 7. 初始化数据库

在云开发控制台「云函数」中运行 `init`：

```js
wx.cloud.callFunction({ name: 'init' })
```

`init` 会自动创建全部集合，并写入默认分类与店铺设置。

### 8. 配置数据库权限

云开发控制台 → 数据库 → 每个集合的「权限设置」→ 选 **「所有用户不可读写」**（仅云函数可访问），保证数据只通过云函数读写、商家权限在云端校验。

### 9. 开通商家身份

1. 在云开发控制台 → 云函数 → `user` → 「配置」中，添加环境变量 `MERCHANT_KEY`，值设为你自己的管理码（不要用弱口令）。
2. 用普通微信登录小程序，进入「个人中心」。
3. 连续点击页面底部版本号 **5 次**，进入商家登录页。
4. 输入第 1 步设置的管理码完成绑定。之后该用户即成为商家，可在「个人中心」看到「商家管理」入口。

### 10. 生成桌台二维码

商家端 → 桌台管理 → 新增桌台 → 生成二维码 → 长按/点击预览保存 → 打印后贴到对应餐桌。用户扫码即进入小程序并自动绑定该桌台。

## 微信支付配置

1. 申请**微信支付商户号**（微信支付官网）。
2. 在云开发控制台 → 「微信支付」中，关联商户号并开通「云开发微信支付」能力。
3. 在「微信支付」设置中，将**支付回调云函数**指定为 `payCallback`。
4. 支付金额在云函数 `order.create` 中按数据库 SKU 重新计算，前端金额不可信。

> 支付回调以 `payCallback` 收到微信通知为准更新订单状态。

## 数据库集合

| 集合 | 说明 |
|---|---|
| users | 用户（openid、昵称、头像、手机号、role 角色） |
| categories | 菜品分类 |
| dishes | 菜品（含 specs 规格组 + skus 规格组合/价格/库存） |
| tables | 桌台（桌号、二维码 fileID、状态） |
| orders | 订单（明细快照、金额分、状态、支付信息） |
| settings | 店铺设置（营业状态、起送价、配送费、公告） |
| banners | 轮播图（预留） |

金额统一以「分」为单位的整数存储。

## 商家端功能

- **菜品管理**：分类、菜品增删改、多规格配置（如份量/辣度）、上下架、库存、图片上传。
- **订单管理**：待接单/制作中/待取餐/配送中等状态流转，接单、拒单（自动退款）、出餐、完成，5 秒自动轮询新订单。
- **桌台管理**：桌号增删、生成小程序码。
- **营业设置**：营业开关、营业时间、起送价、配送费、公告。
- **数据统计**：今日/累计营收、订单数、销量 TOP10。

## 待配置 / 可选增强

- **小票打印**：`merchant.printOrder` 已预留接口，需接入飞鹅/易联云等云打印机。
- **订阅消息**：需在小程序后台申请模板，云函数调 `cloud.openapi.subscribeMessage.send` 推送新订单提醒。
- **TabBar 图标**：当前为纯文字 tab，可自行添加图标图片。
- **轮播图**：`banners` 集合已预留，首页暂未展示。
